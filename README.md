# PP-TOMSK — Доставка правильного питания в Томске

Официальный статический сайт сервиса доставки готовых рационов правильного питания с расчётом КБЖУ в Томске: **[pp-tomsk.ru](https://pp-tomsk.ru)**

---

## Структура проекта

| Файл / папка | Назначение |
| --- | --- |
| `index.html` | Главная посадочная страница: рационы 1000–2500 ккал, пробный сет, примеры блюд, калькулятор КБЖУ и форма заявки |
| `pohudenie.html` | Посадочная страница под рационы для снижения веса (1000 / 1300 / 1500 ккал) |
| `sport-pitanie.html` | Посадочная страница под высокобелковые рационы для тренировок и набора массы (2000 / 2500 ккал) |
| `kalkulyator-kbzhu.html` | Отдельная страница онлайн-калькулятора нормы калорий и БЖУ (формула Миффлина — Сан-Жеора) |
| `privacy.html` | Политика конфиденциальности, обработки персональных данных (152-ФЗ) и cookie |
| `404.html` | Фирменная страница ошибки 404 с быстрым переходом к тарифам и калькулятору |
| `yml-feed.xml` | Единый товарный YML-фид (совместим с **Яндекс Бизнесом** и **2ГИС**) |
| `feed-images/` | Квадратные JPG-иллюстрации блюд для внешних товарных фидов (Яндекс Бизнес / 2ГИС) |
| `dish-*.webp`, `hero-studio.*`, `logo.*` | Оптимизированная графика для быстрой загрузки сайта и превью в соцсетях (`Open Graph`) |
| `site.webmanifest`, `favicon*` | Иконки сайта и манифест установки на главный экран смартфона (`PWA`) |
| `robots.txt`, `sitemap.xml` | Правила индексации, защита от UTM-дублей (`Clean-param`) и карта сайта |
| `CNAME`, `.nojekyll` | Привязка домена `pp-tomsk.ru` и ускоренная прямая выкладка на GitHub Pages без сборки Jekyll |

---

## Памятка при обновлении цен

При изменении стоимости рационов достаточно обновить цифры в:
1. Карточках тарифов и `JSON-LD` на страницах `index.html`, `pohudenie.html`, `sport-pitanie.html`, `kalkulyator-kbzhu.html`.
2. Товарном фиде `yml-feed.xml` (Яндекс Бизнес и 2ГИС подтягивают обновления по прямой ссылке `https://pp-tomsk.ru/yml-feed.xml`).
